# VidhyaPath

VidhyaPath is a modern educational platform for students from Class 9–12, competitive-exam aspirants, college students, and working professionals. Tagline: **"Your Path to Smarter Learning."**

## What's inside

- **Home** — hero, stats, learning categories, why-choose-us, testimonials, and a CTA banner.
- **Courses & Batches** — filterable school batches (Class 9–12, all ₹4,000 or below) and professional upskilling tracks.
- **Notes & Study Material** — a searchable, filterable library of chapter notes and revision material.
- **PYQs & Practice** — interactive practice questions with instant explanations and a progress dashboard.
- **AI Study Assistant** — a mocked chat interface ("VidhyaPath AI") with quick actions for explaining, solving, summarizing, and quizzing.
- **Doubt & Help Center** — a doubt submission form, category selector, and FAQ accordion.
- **Free Courses** — a grid of free learning resources.
- **Contact / Admission** — an admission form (wired to Netlify Forms) plus official contact details.

## Tech stack

- [TanStack Start](https://tanstack.com/start) (React 19 + TanStack Router) for file-based routing and SSR
- Tailwind CSS 4 for styling
- [lucide-react](https://lucide.dev) for icons
- Netlify Forms for the admission form submission
- Deployed on Netlify

## Running locally

```bash
npm install
npm run dev
```

The dev server runs on `http://localhost:3000`.

To build for production:

```bash
npm run build
```
